# Voice profile template

Fill this in by hand if you'd rather not use [prompt 01](prompts/01-build-your-voice-profile.md), or use it to check and correct the profile the AI wrote for you. Keep it under one page. Paste it into a Claude Project, Custom GPT or Gem so every chat starts with it.

---

```markdown
# Voice profile: {{your name}} ({{which channel, e.g. LinkedIn}})

I write for {{who}}. They already know {{what}}. They don't need {{what to skip}}.

## Rhythm
- Sentences: mostly {{short / medium}}; I use fragments {{often / sometimes / never}}.
- Paragraphs: {{1–2}} sentences.
- I open with {{a specific moment / a strong opinion / a number}}.
- I end with {{a point of view / a one-line takeaway / a question}}.

## Words
- I say: {{words and phrases you actually use}}
- I never say: {{words you'd cringe at}}
- Contractions: {{always / mostly}}. Emojis: {{never / max 1}}. Exclamation marks: {{max 1}}.
- Jargon I'm fine with: {{e.g. CAC, funnel, MQL}}. Jargon I explain: {{…}}.

## Stance
- I'm {{confident / curious / contrarian}}. I hedge {{rarely / only about the future}}.
- I disagree by {{e.g. saying so plainly, then giving my reason}}.

## Do
1. {{checkable rule, e.g. Use one real example from my work in every post}}

## Don't
```
